# AI Library

A personal library of AI models, plugins, skills, references, inspiration, UI components and tools, built with Material Design 3.

Plain HTML, CSS and JavaScript — no build step.

## Add a resource

Add an entry to [`data.js`](data.js) (the format is described at the top of the file) and, optionally, a 640×400 screenshot at `thumbs/<id>.png`. Without a screenshot, the card uses a live screenshot of the site.

Items added with the **Add resource** button on the live site are stored only in that browser. Use **⋮ → Export JSON** to copy them into `data.js`.

## Run locally

npx http-server@14.1.1 -p 5173
